# FlexGo Group Web

Página estática. No necesita instalación ni servidor propio.

- `js/datos.js`: contacto, redes, enlaces y aliados. Lo que quede vacío no se muestra.
- `js/datos.js` (`FLEXGO_FAQ`): las preguntas de la página y del chat.
- `css/site.css`: colores y tipografías del manual FlexGo (Space Grotesk e Inter).
- `js/hero3d.js`: escena 3D. Si el dispositivo no puede mostrarla, queda el símbolo plano.

Para verla en tu Mac: `python3 -m http.server 8080` dentro de esta carpeta y abre `http://localhost:8080`.
